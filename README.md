# KrkrzExtract
The next generation of KrkrExtract

# Warning
* Beta version, unstable now (a decade).  
* A modern alternative to this project is [xp3-brute](https://github.com/xmoezzz/xp3-brute), a cross-platform tool that can extract XP3 archives without running the game. It leverages reverse-engineering, Win32 eumlation, symbolic execution, and brute-force techniques to extract.

# Motivation and Limitations
* Much effort has been made to fight against anti-extraction techniques, but the engine itself provides such an interface to read resources, so why not just extract whatever it reads?
* The limitations are clear: (1) Extracting all resources requires playing through the entire game, which is time-consuming; (2) Resources unused during gameplay cannot be extracted.

# Support
KrkrzExtract only supports krkrz engine.
